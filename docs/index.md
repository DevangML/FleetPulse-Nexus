## Getting Started

```bash
bun install      # or npm install
bun run dev      # start the dev server
```

Open the printed localhost URL. Streaming starts automatically; use the control bar to
pause/resume, reset, and change ingestion frequency. See the
[Development Guide](./development-guide.md) for full setup, scripts, and conventions.
